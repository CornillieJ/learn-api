Two tables: where each concept lives in `vwo-api`, and what each .NET
thing you know is called in this stack. Keep this page open in a tab
while you work. For drilling, use the [Flashcards](flashcards.md).

## C# / .NET ↔ Java / Spring equivalents

General equivalents for this stack's generation (Java 17, Spring 5.3,
Boot 2.7, Hibernate 5.6, Spring Security 5.7). Where this repo does
something unusual, the last column says so.

### Language

<div class="table-wrap">

| C# / .NET | Java 17 | Note |
|---|---|---|
| `namespace` / `using` | `package` / `import` | package must match the folder path |
| `{ get; set; }` properties | fields + `getX()`/`setX()` | generated by Lombok here |
| `record` | `record` (accessors `x()`, not `X`) | DTOs in `restAPI/models` |
| `T?`, `?.`, `??` | `Optional<T>`, `.map()`, `.orElse()` | any reference may be `null` |
| `==` on strings | `.equals()` / `Objects.equals()` | `==` is identity; also for boxed ids |
| `decimal` | `BigDecimal` | compare with `compareTo` |
| `DateTime` / `DateOnly` | `LocalDateTime` / `LocalDate` / `Instant` (`java.time`) | |
| `typeof(T)` | `T.class` (only for concrete types) | generics are erased |
| `virtual` / `override` | virtual by default / `@Override` | `final` to opt out |
| `sealed` | `final` | Java 17 `sealed` restricts subclasses instead |
| `internal` | package-private (no modifier) | |
| `const` / `readonly` | `static final` / `final` | |
| attributes `[X]` | annotations `@X` | |
| `IDisposable` + `using` | `AutoCloseable` + try-with-resources | |
| `Func` / `Action` / `Predicate` | `Function` / `Consumer` / `Supplier` / `Predicate` | |
| extension methods | none (static helper classes) | |
| unchecked exceptions only | checked + unchecked | `throws` clauses |
| `async` / `await`, `Task<T>` | `CompletableFuture<T>`, blocking servlet threads | this API is synchronous |

</div>
