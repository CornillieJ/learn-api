# API Endpoints

This page maps every v1 and v2 route across the API's 31 (v1) and 29 (v2) controllers, pairing each route with the shared version-less interface it implements and flagging deprecations and version-only endpoints. v1 and v2 are almost entirely the same surface under different base paths, with v1 carrying extra legacy routes and only two endpoints that are genuinely v2 only. Use the search box and filter chips to narrow the list by method, controller, or flag.
