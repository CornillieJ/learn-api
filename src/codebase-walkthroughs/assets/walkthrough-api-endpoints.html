API Endpoint Map

Every v1 and v2 route across 31 (v1) / 29 (v2) controllers, paired by the shared version-less interface they implement, with deprecation and version-exclusivity flags.

v1 and v2 are almost entirely the same surface under different base paths (/api/v1 + legacy /restapi alias vs. /api/v2 only) — every v2 interface is also implemented by a v1 controller. The real differences are: v1 carries extra legacy/deprecated methods that v2 dropped, a few v1 routes were renamed on the way to v2 (shown as "changed"), and there are exactly two genuinely v2-only endpoints (GET /user/{id} and GET /user/get) that replaced the old standalone PersoonController, which itself has no v2 equivalent at all. One interface method (SurveyAnswersController create/update) is missing its HTTP-mapping annotation in v2 and is not actually reachable there.
